# Story: AI suggested solutions

**Number**: 33
**Area**: AI Features
**Priority**: P3

## What do we want?

**As a** Agent, **I want to** see suggested solutions from similar past tickets, **so that** resolution is faster.

## Context

This story is one of the AI Features capabilities from the source feature list. It matters because without it, a(n) Agent cannot see suggested solutions from similar past tickets, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a ticket similar to past resolved tickets, **When** an agent views it, **Then** relevant past solutions are suggested

## Why it matters

Resolution is faster. Priority P3 reflects how central this is relative to the rest of the AI Features area and the product as a whole — see `../../specs/33-ai-suggested-solutions/spec.md` for the full technical specification of exactly what the system must do.
