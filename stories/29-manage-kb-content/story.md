# Story: Manage knowledge base content

**Number**: 29
**Area**: Knowledge Base
**Priority**: P3

## What do we want?

**As a** Admin, **I want to** create or edit a knowledge base article, **so that** information stays current.

## Context

This story is one of the Knowledge Base capabilities from the source feature list. It matters because without it, a(n) Admin cannot create or edit a knowledge base article, which blocks the value described above from being delivered.

## Example

Concretely: **Given** an admin/agent with permission, **When** they create or edit an article, **Then** the change is published and searchable

## Why it matters

Information stays current. Priority P3 reflects how central this is relative to the rest of the Knowledge Base area and the product as a whole — see `../../specs/29-manage-kb-content/spec.md` for the full technical specification of exactly what the system must do.
