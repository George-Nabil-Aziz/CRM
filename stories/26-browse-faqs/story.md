# Story: Browse FAQs

**Number**: 26
**Area**: Knowledge Base
**Priority**: P3

## What do we want?

**As a** Customer, **I want to** browse a list of FAQs, **so that** I can self-serve an answer.

## Context

This story is one of the Knowledge Base capabilities from the source feature list. It matters because without it, a(n) Customer cannot browse a list of FAQs, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a customer or agent, **When** they open the knowledge base, **Then** a list of FAQs is available to browse

## Why it matters

I can self-serve an answer. Priority P3 reflects how central this is relative to the rest of the Knowledge Base area and the product as a whole — see `../../specs/26-browse-faqs/spec.md` for the full technical specification of exactly what the system must do.
