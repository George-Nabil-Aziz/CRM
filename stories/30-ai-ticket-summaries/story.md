# Story: AI ticket summaries

**Number**: 30
**Area**: AI Features
**Priority**: P3

## What do we want?

**As a** Agent, **I want to** see an AI-generated summary of a long ticket thread, **so that** I can understand it quickly.

## Context

This story is one of the AI Features capabilities from the source feature list. It matters because without it, a(n) Agent cannot see an AI-generated summary of a long ticket thread, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a ticket with a long thread, **When** an agent opens it, **Then** an AI-generated summary is shown

## Why it matters

I can understand it quickly. Priority P3 reflects how central this is relative to the rest of the AI Features area and the product as a whole — see `../../specs/30-ai-ticket-summaries/spec.md` for the full technical specification of exactly what the system must do.
