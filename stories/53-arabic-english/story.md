# Story: Arabic and English

**Number**: 53
**Area**: Platform
**Priority**: P4

## What do we want?

**As a** User, **I want to** switch the interface language, **so that** I can use the system in my language.

## Context

This story is one of the Platform capabilities from the source feature list. It matters because without it, a(n) User cannot switch the interface language, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a user, **When** they switch language, **Then** the UI displays in Arabic (RTL) or English accordingly

## Why it matters

I can use the system in my language. Priority P4 reflects how central this is relative to the rest of the Platform area and the product as a whole — see `../../specs/53-arabic-english/spec.md` for the full technical specification of exactly what the system must do.
