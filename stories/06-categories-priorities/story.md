# Story: Categories and priorities

**Number**: 06
**Area**: Ticket Management
**Priority**: P1

## What do we want?

**As a** Agent, **I want to** set a ticket's category and priority, **so that** it's tagged and filterable correctly.

## Context

This story is one of the Ticket Management capabilities from the source feature list. It matters because without it, a(n) Agent cannot set a ticket's category and priority, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a new ticket, **When** an agent sets a category and priority, **Then** the ticket is tagged accordingly and filterable by both

## Why it matters

It's tagged and filterable correctly. Priority P1 reflects how central this is relative to the rest of the Ticket Management area and the product as a whole — see `../../specs/06-categories-priorities/spec.md` for the full technical specification of exactly what the system must do.
