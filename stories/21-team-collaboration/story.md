# Story: Team collaboration

**Number**: 21
**Area**: Agent Dashboard
**Priority**: P2

## What do we want?

**As a** Agent, **I want to** add an internal note and mention a teammate on a ticket, **so that** we can resolve complex issues together.

## Context

This story is one of the Agent Dashboard capabilities from the source feature list. It matters because without it, a(n) Agent cannot add an internal note and mention a teammate on a ticket, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a ticket needs another agent's input, **When** an agent adds an internal note or mention, **Then** the mentioned teammate is notified and can view it

## Why it matters

We can resolve complex issues together. Priority P2 reflects how central this is relative to the rest of the Agent Dashboard area and the product as a whole — see `../../specs/21-team-collaboration/spec.md` for the full technical specification of exactly what the system must do.
