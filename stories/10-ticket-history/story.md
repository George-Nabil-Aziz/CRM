# Story: View ticket history

**Number**: 10
**Area**: Ticket Management
**Priority**: P1

## What do we want?

**As a** Agent, **I want to** view a ticket's full history, **so that** I can see every action taken on it.

## Context

This story is one of the Ticket Management capabilities from the source feature list. It matters because without it, a(n) Agent cannot view a ticket's full history, which blocks the value described above from being delivered.

## Example

Concretely: **Given** any ticket, **When** an agent opens it, **Then** a full timestamped log of status changes and actions is visible

## Why it matters

I can see every action taken on it. Priority P1 reflects how central this is relative to the rest of the Ticket Management area and the product as a whole — see `../../specs/10-ticket-history/spec.md` for the full technical specification of exactly what the system must do.
