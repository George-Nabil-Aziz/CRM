# Story: Agent performance reports

**Number**: 42
**Area**: Reports & Management
**Priority**: P3

## What do we want?

**As a** Manager, **I want to** view agent performance, **so that** I can evaluate the team.

## Context

This story is one of the Reports & Management capabilities from the source feature list. It matters because without it, a(n) Manager cannot view agent performance, which blocks the value described above from being delivered.

## Example

Concretely: **Given** agent activity data, **When** a manager runs the report, **Then** resolution time and ticket counts per agent are shown

## Why it matters

I can evaluate the team. Priority P3 reflects how central this is relative to the rest of the Reports & Management area and the product as a whole — see `../../specs/42-agent-performance-reports/spec.md` for the full technical specification of exactly what the system must do.
