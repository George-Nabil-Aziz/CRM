# Story: Search knowledge base

**Number**: 28
**Area**: Knowledge Base
**Priority**: P3

## What do we want?

**As a** Agent, **I want to** search the knowledge base, **so that** I can quickly find a solution to reference.

## Context

This story is one of the Knowledge Base capabilities from the source feature list. It matters because without it, a(n) Agent cannot search the knowledge base, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a search term, **When** it is entered, **Then** relevant FAQs/articles are returned

## Why it matters

I can quickly find a solution to reference. Priority P3 reflects how central this is relative to the rest of the Knowledge Base area and the product as a whole — see `../../specs/28-search-knowledge-base/spec.md` for the full technical specification of exactly what the system must do.
