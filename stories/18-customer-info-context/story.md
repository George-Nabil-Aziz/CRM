# Story: View customer information in context

**Number**: 18
**Area**: Agent Dashboard
**Priority**: P2

## What do we want?

**As a** Agent, **I want to** see the customer's info while viewing a ticket, **so that** I have context without switching screens.

## Context

This story is one of the Agent Dashboard capabilities from the source feature list. It matters because without it, a(n) Agent cannot see the customer's info while viewing a ticket, which blocks the value described above from being delivered.

## Example

Concretely: **Given** an agent opens a ticket, **When** they view it, **Then** the related customer's profile info is shown alongside it

## Why it matters

I have context without switching screens. Priority P2 reflects how central this is relative to the rest of the Agent Dashboard area and the product as a whole — see `../../specs/18-customer-info-context/spec.md` for the full technical specification of exactly what the system must do.
