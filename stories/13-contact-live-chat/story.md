# Story: Contact via live chat

**Number**: 13
**Area**: Communication Channels
**Priority**: P2

## What do we want?

**As a** Customer, **I want to** start a live chat, **so that** I get help in real time.

## Context

This story is one of the Communication Channels capabilities from the source feature list. It matters because without it, a(n) Customer cannot start a live chat, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a customer starts a live chat, **When** they send a message, **Then** a ticket/conversation is created and an agent can respond in real time

## Why it matters

I get help in real time. Priority P2 reflects how central this is relative to the rest of the Communication Channels area and the product as a whole — see `../../specs/13-contact-live-chat/spec.md` for the full technical specification of exactly what the system must do.
