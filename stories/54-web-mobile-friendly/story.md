# Story: Web and mobile friendly

**Number**: 54
**Area**: Platform
**Priority**: P4

## What do we want?

**As a** User, **I want to** use the CRM on web and mobile, **so that** I can access it from any device.

## Context

This story is one of the Platform capabilities from the source feature list. It matters because without it, a(n) User cannot use the CRM on web and mobile, which blocks the value described above from being delivered.

## Example

Concretely: **Given** any user, **When** they access the CRM from a phone or desktop browser, **Then** the interface adapts and remains fully usable

## Why it matters

I can access it from any device. Priority P4 reflects how central this is relative to the rest of the Platform area and the product as a whole — see `../../specs/54-web-mobile-friendly/spec.md` for the full technical specification of exactly what the system must do.
