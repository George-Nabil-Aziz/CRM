# Story: Manage tasks and reminders

**Number**: 19
**Area**: Agent Dashboard
**Priority**: P2

## What do we want?

**As a** Agent, **I want to** set a reminder on a ticket, **so that** I don't forget to follow up.

## Context

This story is one of the Agent Dashboard capabilities from the source feature list. It matters because without it, a(n) Agent cannot set a reminder on a ticket, which blocks the value described above from being delivered.

## Example

Concretely: **Given** an agent sets a reminder on a ticket, **When** its due time arrives, **Then** the agent is notified

## Why it matters

I don't forget to follow up. Priority P2 reflects how central this is relative to the rest of the Agent Dashboard area and the product as a whole — see `../../specs/19-tasks-reminders/spec.md` for the full technical specification of exactly what the system must do.
