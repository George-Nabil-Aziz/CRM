# Story: External systems

**Number**: 52
**Area**: Integrations
**Priority**: P4

## What do we want?

**As a** Admin, **I want to** connect another external system, **so that** data flows without manual entry.

## Context

This story is one of the Integrations capabilities from the source feature list. It matters because without it, a(n) Admin cannot connect another external system, which blocks the value described above from being delivered.

## Example

Concretely: **Given** another external system is connected, **When** relevant data changes, **Then** it syncs into the CRM without manual re-entry

## Why it matters

Data flows without manual entry. Priority P4 reflects how central this is relative to the rest of the Integrations area and the product as a whole — see `../../specs/52-external-systems/spec.md` for the full technical specification of exactly what the system must do.
