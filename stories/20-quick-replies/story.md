# Story: Use quick replies

**Number**: 20
**Area**: Agent Dashboard
**Priority**: P2

## What do we want?

**As a** Agent, **I want to** insert a quick-reply template into a response, **so that** I can respond faster to common questions.

## Context

This story is one of the Agent Dashboard capabilities from the source feature list. It matters because without it, a(n) Agent cannot insert a quick-reply template into a response, which blocks the value described above from being delivered.

## Example

Concretely: **Given** an open ticket, **When** an agent selects a quick-reply template, **Then** it is inserted into the response

## Why it matters

I can respond faster to common questions. Priority P2 reflects how central this is relative to the rest of the Agent Dashboard area and the product as a whole — see `../../specs/20-quick-replies/spec.md` for the full technical specification of exactly what the system must do.
