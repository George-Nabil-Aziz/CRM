# Story: AI suggested replies

**Number**: 31
**Area**: AI Features
**Priority**: P3

## What do we want?

**As a** Agent, **I want to** get an AI-suggested reply, **so that** I can respond faster.

## Context

This story is one of the AI Features capabilities from the source feature list. It matters because without it, a(n) Agent cannot get an AI-suggested reply, which blocks the value described above from being delivered.

## Example

Concretely: **Given** an open ticket, **When** an agent requests a suggestion, **Then** a contextually relevant reply is proposed

## Why it matters

I can respond faster. Priority P3 reflects how central this is relative to the rest of the AI Features area and the product as a whole — see `../../specs/31-ai-suggested-replies/spec.md` for the full technical specification of exactly what the system must do.
