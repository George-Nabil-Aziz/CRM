# Story: View interaction history

**Number**: 03
**Area**: Customer Management
**Priority**: P1

## What do we want?

**As a** Agent, **I want to** view a customer's full interaction history, **so that** I have context before responding.

## Context

This story is one of the Customer Management capabilities from the source feature list. It matters because without it, a(n) Agent cannot view a customer's full interaction history, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a customer with past tickets/conversations, **When** an agent opens their profile, **Then** the full interaction history is displayed in chronological order

## Why it matters

I have context before responding. Priority P1 reflects how central this is relative to the rest of the Customer Management area and the product as a whole — see `../../specs/03-interaction-history/spec.md` for the full technical specification of exactly what the system must do.
