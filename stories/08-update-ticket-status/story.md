# Story: Update ticket status

**Number**: 08
**Area**: Ticket Management
**Priority**: P1

## What do we want?

**As a** Agent, **I want to** change a ticket's status, **so that** progress is visible to everyone.

## Context

This story is one of the Ticket Management capabilities from the source feature list. It matters because without it, a(n) Agent cannot change a ticket's status, which blocks the value described above from being delivered.

## Example

Concretely: **Given** an open ticket, **When** an agent changes its status, **Then** the new status is reflected immediately

## Why it matters

Progress is visible to everyone. Priority P1 reflects how central this is relative to the rest of the Ticket Management area and the product as a whole — see `../../specs/08-update-ticket-status/spec.md` for the full technical specification of exactly what the system must do.
