# Story: Create customer profile

**Number**: 01
**Area**: Customer Management
**Priority**: P1

## What do we want?

**As a** Agent, **I want to** create a customer profile, **so that** I can start tracking their information and history.

## Context

This story is one of the Customer Management capabilities from the source feature list. It matters because without it, a(n) Agent cannot create a customer profile, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a new customer, **When** an agent creates a profile, **Then** it is saved and searchable

## Why it matters

I can start tracking their information and history. Priority P1 reflects how central this is relative to the rest of the Customer Management area and the product as a whole — see `../../specs/01-customer-profile/spec.md` for the full technical specification of exactly what the system must do.
