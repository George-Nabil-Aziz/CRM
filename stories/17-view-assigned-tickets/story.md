# Story: View assigned tickets

**Number**: 17
**Area**: Agent Dashboard
**Priority**: P2

## What do we want?

**As a** Agent, **I want to** see all tickets assigned to me, **so that** I know my workload at a glance.

## Context

This story is one of the Agent Dashboard capabilities from the source feature list. It matters because without it, a(n) Agent cannot see all tickets assigned to me, which blocks the value described above from being delivered.

## Example

Concretely: **Given** an agent has tickets assigned, **When** they open their dashboard, **Then** all assigned tickets are listed with status/priority

## Why it matters

I know my workload at a glance. Priority P2 reflects how central this is relative to the rest of the Agent Dashboard area and the product as a whole — see `../../specs/17-view-assigned-tickets/spec.md` for the full technical specification of exactly what the system must do.
