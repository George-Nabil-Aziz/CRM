# Story: System configuration

**Number**: 48
**Area**: Security & Administration
**Priority**: P2

## What do we want?

**As a** Admin, **I want to** change a system setting, **so that** the CRM fits our workflows.

## Context

This story is one of the Security & Administration capabilities from the source feature list. It matters because without it, a(n) Admin cannot change a system setting, which blocks the value described above from being delivered.

## Example

Concretely: **Given** an admin, **When** they change a system setting, **Then** the new setting takes effect across the system

## Why it matters

The CRM fits our workflows. Priority P2 reflects how central this is relative to the rest of the Security & Administration area and the product as a whole — see `../../specs/48-system-configuration/spec.md` for the full technical specification of exactly what the system must do.
