# Story: Response/resolution targets

**Number**: 22
**Area**: SLA & Automation
**Priority**: P2

## What do we want?

**As a** Admin, **I want to** set response and resolution time targets per category, **so that** service quality is measurable.

## Context

This story is one of the SLA & Automation capabilities from the source feature list. It matters because without it, a(n) Admin cannot set response and resolution time targets per category, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a ticket category, **When** an admin sets SLA response/resolution targets, **Then** every new ticket in that category inherits them

## Why it matters

Service quality is measurable. Priority P2 reflects how central this is relative to the rest of the SLA & Automation area and the product as a whole — see `../../specs/22-sla-targets/spec.md` for the full technical specification of exactly what the system must do.
