# Story: Submit via web form

**Number**: 15
**Area**: Communication Channels
**Priority**: P2

## What do we want?

**As a** Customer, **I want to** submit a web form, **so that** I can report an issue from the website without logging in.

## Context

This story is one of the Communication Channels capabilities from the source feature list. It matters because without it, a(n) Customer cannot submit a web form, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a customer fills out a web form, **When** they submit it, **Then** a ticket is created from the form data

## Why it matters

I can report an issue from the website without logging in. Priority P2 reflects how central this is relative to the rest of the Communication Channels area and the product as a whole — see `../../specs/15-submit-web-form/spec.md` for the full technical specification of exactly what the system must do.
