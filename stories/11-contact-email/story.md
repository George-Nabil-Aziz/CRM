# Story: Contact via email

**Number**: 11
**Area**: Communication Channels
**Priority**: P2

## What do we want?

**As a** Customer, **I want to** email support about an issue, **so that** I don't need to use a different channel.

## Context

This story is one of the Communication Channels capabilities from the source feature list. It matters because without it, a(n) Customer cannot email support about an issue, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a customer emails support, **When** the message is received, **Then** a ticket is created/updated from it

## Why it matters

I don't need to use a different channel. Priority P2 reflects how central this is relative to the rest of the Communication Channels area and the product as a whole — see `../../specs/11-contact-email/spec.md` for the full technical specification of exactly what the system must do.
