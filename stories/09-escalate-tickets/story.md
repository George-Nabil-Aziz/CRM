# Story: Escalate tickets

**Number**: 09
**Area**: Ticket Management
**Priority**: P1

## What do we want?

**As a** Agent, **I want to** escalate a ticket, **so that** it gets attention from a supervisor.

## Context

This story is one of the Ticket Management capabilities from the source feature list. It matters because without it, a(n) Agent cannot escalate a ticket, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a ticket needing higher-level attention, **When** an agent or the system escalates it, **Then** it is flagged and visible to supervisors

## Why it matters

It gets attention from a supervisor. Priority P1 reflects how central this is relative to the rest of the Ticket Management area and the product as a whole — see `../../specs/09-escalate-tickets/spec.md` for the full technical specification of exactly what the system must do.
