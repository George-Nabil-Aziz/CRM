# Story: Automatic categorization

**Number**: 32
**Area**: AI Features
**Priority**: P3

## What do we want?

**As a** System, **I want to** auto-suggest a category for a new ticket, **so that** manual tagging is reduced.

## Context

This story is one of the AI Features capabilities from the source feature list. It matters because without it, a(n) System cannot auto-suggest a category for a new ticket, which blocks the value described above from being delivered.

## Example

Concretely: **Given** a new ticket, **When** it is created, **Then** the system suggests/assigns a category automatically

## Why it matters

Manual tagging is reduced. Priority P3 reflects how central this is relative to the rest of the AI Features area and the product as a whole — see `../../specs/32-automatic-categorization/spec.md` for the full technical specification of exactly what the system must do.
